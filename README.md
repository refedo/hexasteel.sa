# HEXA Steel® Website V3

Clean-slate public website rebuild, using the existing repository and a nonproduction branch. The legacy source has a preserved archive branch. This milestone is an alpha foundation, not a live release.

## Run
- Node.js 22; run npm install, npm run dev, npm run check and npm run build.
- Copy .env.example to .env.local for Sanity/email configuration.
- Provision a Sanity project and run npm run studio after configuring its project ID.

## Release gates
- Implement editorial live preview, bilingual EN/AR and content approval.
- Complete secure RFQ and vendor portal, private uploads, anti-spam and transactional email.
- Replace provisional steel-line illustration with original approved photography.
- Validate machinery specifications, ISO validity, Aramco and MODON approval scope.
- Commit dependency lockfile generated by an online install.
- Review the unfinished V3 site directly on hexasteel.sa under a controlled pre-launch configuration; use a separate deploy job from rebuild/website-v3 and do not merge into main to deploy.
- No automatic production deployment is included in this branch.

## Direct-domain pre-launch policy (CEO decision, October 2026)
- Use **https://hexasteel.sa** for design and functional reviews. No staging.hexasteel.sa is required.
- The domain remains a **pre-launch review environment** until formal acceptance. Configure restrictive access where practicable; at minimum maintain noindex and confirm crawlers are blocked by meta or response headers. Remember noindex is not access control.
- Implement manual / gated GitHub Actions deployment from **rebuild/website-v3**; never run the legacy main deploy script against the V3 application.
- Verify DigitalOcean server, Nginx mapping, PM2 service identity, Node runtime and DNS before switching traffic; back up the current files/configuration for rollback.
- Disable incomplete RFQ uploads, vendor portal, and outbound email until security and integration tests pass.
- Use maintenance/review headers, monitor errors and keep the previous version restorable.
- After final approval, remove access restriction and noindex and switch to controlled releases.
